# 功能点清单

本文件逐项说明 `logistics-management` 的功能点。按工具名统计共 **38 个**（3 个元功能 +
16 个报销 + 9 个工资 + 2 个汇总 + 4 个制表 + 4 个报单）。另有一组通用 Agent 接入能力，
它们包装上述工具，不新增业务 action。

## 边界原则

- 统一入口只做路由、配置读取和结果输出；业务脚本全部在本工具包的 `modules/` 内。
- 各模块目录自带脚本、配置、文档和 state；不直接 import 其他模块代码。
- 唯一允许的跨模块业务依赖：`driver-wage` 与 `driver-monthly-sheet` **只读**报销台账
  `modules/reimbursement/state/ledger.sqlite`。
- 写入类功能默认 dry-run 或有硬闸门；外发类功能发送前必须跑 `bot_check`。
- 报单不重复实现报销去重；它有自己的历史池，并调用内置 `monthly_sheet` 写表。

## 2. 司机报销（`modules/reimbursement/`）

| `resolve` | 逐条解析凭证归属司机 | 消息发送者、文本、凭证附件 | 每条记录的司机归属 | 名册、报销配置 | 归集流程自动调用 |
| `dedup_check` | 单条凭证去重 | 单条凭证字段 | 命中/未命中及命中层 | 台账、群历史池、报表明细 | 归集流程 / 手动 |
| `dedup_batch` | 批量凭证去重 | 一批凭证 | 唯一记录 + 重复记录 | 同上 | 归集流程 |
| `ledger_add` | 唯一凭证入账 | 去重后的凭证 | 台账 entry | `ledger.sqlite` | 归集流程写阶段 |
| `balance` | 按司机四态/未结查询 | 可选司机名 | 已报销/待打款/需补材料/重复等统计 | `ledger.sqlite` | 手动 / 月初月报 |
| `index_add` | 凭证入历史池 | 群内出现的每张凭证 | `voucher_seen` 记录 | 台账索引 | 每轮拉群消息后 |
| `write_detail` | 写唯一报销明细 sheet | 本轮新入账明细 | 司机报表中的「N月报销明细」sheet | 目标司机 xlsx、zip 写入器 | 入账后 |
| `group_task` | 建报销确认任务 | 每位司机本轮新入账 | 飞书任务链接并挂「报销」清单 | `lark-cli`、任务清单配置 | 入账后，闭环必需 |
| `notify` | 群+负责人两层通报 | 本轮结果或无新数据标记 | 群简洁通报 + 负责人专业版；无新数据只发一句 | `lark-cli`、bot_check | 归集结束 |
| `monthly` | 月初月报 | 上月台账 | 按司机/四态/环比的月报 | `ledger.sqlite` | 每月 1–4 号自动化 |
| `mention_gate` | @ 触发门槛 | `chat_id`、消息内容 | `gate_ok` | `mention_policy` | 群 @ |
| `mention_classify` | @ 权限分级 | 发送者 `open_id` | `admin` / `limited` | `mention_policy` | 群 @ |
| `mention_ack` | 先回应再执行 | `run_id`、渠道 | 调侃式「收到」消息，固定 bot 身份 | `lark-cli` | 群 @ 第一步 |
| `bot_check` | 飞书机器人配置自检 | 可选 `--chat-id` | `bot_setup_required`、问题清单、教程 | `lark-cli`、内置教程 | 任何外发前 |
| `driver_copy` | 生成群内极简文案 | 本轮报销结果 | 大白话文案，不暴露底层路径 | 报销配置 | `notify` 组稿时 |

## 3. 司机工资（`modules/driver-wage/`）

| 名称 | 用途 | 输入 | 输出 | 依赖 | 触发方式 |
|---|---|---|---|---|---|
| `sync_roster` | 同步飞书主名册 | 飞书通讯录/群成员 | 名册缓存 | `lark-cli`、工资配置 | 计算前手动/自动化 |
| `compute` | 按规则计算工资 | 当月趟数/账单、规则、名册、报销加项 | 逐行明细、人汇总、结果指纹 | 内置报销台账、工资配置 | 手动 / 每月 10 号 |
| `verify` | 独立路径复算与核对 | `compute` 结果 | `PASS` / `REVIEW` / `BLOCK` 与核对报告 | 规则、台账、外部账单 | `compute` 后，BLOCK 即停 |
| `preview` | 生成待确认预览 | `verify=PASS` 结果 | 待确认清单，绝不私发 | 闸门状态 | 定时任务终点 |
| `confirm` | 发起人确认硬闸门 | token + 结果指纹 | 已确认状态 | `gate_secret`、有效期 | 负责人手动；Agent 不得代确认 |
| `dispatch` | 一人一条私发工资条 | 已确认结果、名册 | 私发结果 JSON；默认 dry-run | `lark-cli`、名册 | `confirm` 后 |
| `status` | 查状态/确认/回执 | 月份或 token | 当前状态与回执 | 工资 state | 手动 |
| `validate` | 人话配置校验 | `config/local/*.json` | `verdict`、`errors`、`warnings` | 规则与配置 | 接入时 / 排障 |
| `init` | 引导式接入 | 交互式回答 | 草稿配置 | 配置模板 | 新环境初始化 |

固定顺序：`sync_roster → compute → verify → preview → confirm → dispatch`。

## 4. 月度汇总（`modules/driver-month-report/`）

| 名称 | 用途 | 输入 | 输出 | 依赖 | 触发方式 |
|---|---|---|---|---|---|
| `inspect` | 查看识别到的原始数值 | 各司机月份 sheet、`report.json` | 识别值清单 | 源 xlsx、汇总配置 | 手动 / 调试 |
| `generate` | 重生成月度汇总 | 同上 + 月份/环比配置 | 三张表：月度汇总、项目明细、口径与校验 | 源 xlsx、`item_rules.json` | 手动；旧表先回收到 `.recycle/` |

口径：`净利润 = 运费收入 − 工资 − 其他支出`；环比只比配置的上一个月。

## 6. 报单（`scripts/intake.py`）

| 名称 | 用途 | 输入 | 输出 | 依赖 | 触发方式 |
|---|---|---|---|---|---|
| `parse` | 飞书运输单结构化 | `--messages` JSON、可选附件 | 结构化记录 JSON | `intake.fields` 别名 | 手动 |
| `plan` | 预览归属、去重、分组 | parse 结果、年月 | 计划 JSON；不写历史池、不写真表 | 历史池 `seen.jsonl` | `run` 前，只读 |
| `run` | 生成数据源并写表 | parse 结果、附件、年月 | 标准数据源 xlsx；`--no-dry-run` 才写司机表 | 内置 `monthly_sheet.run` | 手动；默认 dry-run |
| `selftest` | 报单脱敏自测 | 无 | 检查结果 JSON；不写真表、不连飞书 | 临时目录 | 手动 / CI |

## 7. 通用 Agent 接入能力（`scripts/agent.py`）

| 名称 | 用途 | 输入 | 输出 | 依赖 | 触发方式 |
|---|---|---|---|---|---|
| `list` | 输出完整工具清单 | `config/agent_tools.json` | 38 个工具的 JSON | 工具清单 | CLI / Agent 发现 |
| `describe` | 查看单个工具定义 | 工具名 | 单个工具 JSON | 工具清单 | CLI / Agent 发现 |
| `call` | 以统一 argv 方式调用任一工具 | 工具名 + args/kwargs | 单一调用结果 JSON | `agent_runtime.py` | 任意 Agent / 脚本 |
| `serve` | 启动 MCP stdio 服务器 | JSON-RPC 消息 | `tools/list` / `tools/call` 响应 | `mcp_server.py` | MCP 客户端 |

安全模型：`read` 默认允许；`write` 需 `LOGISTICS_ALLOW_WRITE=1`；`external` 需
`LOGISTICS_ALLOW_EXTERNAL=1`；`--help` 不受限制。详见 [通用Agent接入](通用Agent接入.md)。

## 8. 模块间依赖矩阵

| 模块 | 读取 | 写入 | 说明 |
|---|---|---|---|
| `reimbursement` | 飞书群消息、司机报表 | 内置台账、报销明细 sheet、飞书任务/通知 | 台账是报销状态真源 |
| `driver-wage` | 内置台账（只读）、工资配置、名册 | 工资结果、工资条私发 | 不写报销台账 |
| `driver-month-report` | 各司机月份 sheet、汇总配置 | 月度汇总三张表 | 不写各司机明细 sheet |
| `driver-monthly-sheet` | 模板、数据源、内置台账（只读） | 各司机月份 sheet | 被报单复用 |
| `intake` | 飞书消息、附件 | 标准数据源；调用制表写 sheet | 不重复实现报销去重 |
