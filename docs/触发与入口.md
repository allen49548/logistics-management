# 触发与入口

## 统一入口

`python3 scripts/logistics.py <group> <action> [参数...]`

| group | 含义 | action（见 `logistics list`） |
|---|---|---|
| `list` / `config` / `doctor` | 元命令 | — |
| `reimb` | 司机报销 | sync_roster / resolve / dedup_check / dedup_batch / ledger_add / balance / index_add / write_detail / group_task / notify / monthly / mention_gate / mention_classify / mention_ack / bot_check / driver_copy |
| `wage` | 工资计算与核对 | compute / verify / preview / confirm / dispatch / sync_roster / status / validate / init |
| `summary` | 月度汇总 | generate / inspect |
| `sheet` | 月度制表 | inspect / plan / run / selftest |
| `intake` | 报单（新增） | parse / plan / run / selftest |

约定：action 之后的 `extra` 参数原样透传给目标脚本（`argparse.REMAINDER`），
例如 `logistics wage preview --month 2026-08`。
内置模块脚本的 stdout 原样输出（它是结果 JSON），路由元数据写 stderr。

## 通用 Agent 入口

任意支持 shell / function calling / MCP 的 agent 使用同一套工具：

```bash
python3 scripts/agent.py list
python3 scripts/agent.py describe logistics_doctor
python3 scripts/agent.py call logistics_doctor
python3 scripts/agent.py serve
```

- 工具真源：`config/agent_tools.json`（38 个工具）。
- `call` 返回单一 JSON；MCP `tools/call` 返回同一结果的文本包裹。
- 安全门控见 [通用Agent接入](通用Agent接入.md)。

## 触发方式

### 1）对话 / 命令行
用户自然语言提出意图，Agent 解析后调用对应命令。典型映射：

| 用户说 | 调用 |
|---|---|
| 归集报销 / 同步付款凭证 | `logistics reimb …`（按 reimbursement 流程多步） |
| 算某月工资 / 核对工资 | `logistics wage compute/verify --month YYYY-MM` |
| 生成月度汇总 / 环比报表 | `logistics summary generate` |
| 把群里运输单做成司机报表 | `logistics intake parse/plan/run` |

### 2）群 @（唯一真源：reimbursement.mention.py）
```
mention gate（群/内容门槛）→ classify（open_id 判 admin/limited）
  → ack（调侃「收到」，固定 --as bot）→ 按 allowed 执行
```
- 群门槛：`mention_policy.trigger.allowed_chat_ids`，其他群拒绝；
- 内容门槛：`content_keywords=[]` 表示不限内容；
- 权限：负责人可处理异常/改规则；司机只能触发正常业务，禁止改规则/代码；
- 飞书 @ 非实时 webhook，靠主动拉群消息检测。

工具包的 `reimb mention_gate / mention_classify / mention_ack` 只是内置模块路由，**不另建逻辑**。

### 3）定时（沿用内置模块口径，不在工具包内新建）
- 月初月报：每月 1–4 号 09:00（内置 reimbursement 的 `monthly_summary.py`）。
- 工资：每月 10 号 09:00，只到 preview（内置 driver-wage）。
- 报销日常归集：当前无定时任务（与现状一致，不重建）。
- 报单：默认按需；如需定时由部署环境自行创建，本工具包不擅自新建自动化。

### 4）飞书通道约定
- 读群消息：`lark-cli im +chat-messages-list --as user --page-all --order asc --no-reactions --download-resources`。
- 发送：配置指定的统一 bot；发送前 `bot_check` 自检；未配置则转述教程、不冒充个人身份。
- 白名单：发送前精确校验 chat_id，禁止模糊匹配发错群。
