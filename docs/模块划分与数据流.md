# 模块划分与数据流

## 一、分层

```
┌─────────────────────────────────────────────────────────┐
│ 触发层   对话意图 / 群 @ / 定时自动化                      │
│          （@ 门槛与权限真源：reimbursement.mention.py）    │
├─────────────────────────────────────────────────────────┤
│ 门面层   logistics.py：意图→模块路由、聚合、doctor         │
│          只输出路由元数据到 stderr，子脚本 stdout 原样透传 │
├──────────────────────────┬──────────────────────────────┤
│ 内置业务层（modules/）     │ 报单层（本 skill 新增）        │
│  reimbursement           │  intake.py                    │
│  driver-wage             │  飞书运输单解析/字段识别/       │
│  driver-month-report     │  司机归属/去重/数据源生成       │
│  driver-monthly-sheet    │                               │
├──────────────────────────┴──────────────────────────────┤
│ 数据层   ledger.sqlite / 各司机 {司机}{年}.xlsx / 配置 JSON │
└─────────────────────────────────────────────────────────┘
```

## 二、模块职责与不重叠边界

| 模块 | 只做什么 | 不做什么（避免重复逻辑） |
|---|---|---|
| reimbursement | 报销凭证归集、去重、报销明细 sheet、确认任务、通报、月初月报 | 不算工资、不做运输单、不做净利润汇总 |
| driver-wage | 按规则算工资 + 核对 + 确认闸门 + 私发 | 不归集报销（只读台账作加项）、不写报表汇总、不做车贷/净利润 |
| driver-month-report | 运费/工资/支出识别、净利润、环比汇总表 | 不写各司机明细 sheet、不管报销凭证 |
| driver-monthly-sheet | 按模板插入月份 sheet、填运输与报销 | 不解析飞书消息、不算工资、不发通知 |
| intake（新） | 解析飞书运输单→结构化→分组→数据源 | **不自己写 xlsx 报表**（调用内置 monthly_sheet）、不重复去重逻辑于报销 |

## 三、数据流

### 3.1 报销流
```
飞书群付款凭证截图
  → driver_roster.resolve（发送者→司机）
  → ledger.check-batch（四方池六层去重）
  → reimb_detail.apply（写唯一「N月报销明细」sheet）
  → group_task.create（确认任务，闭环）
  → notify.py（群极简 + 负责人专业版）
  → ledger.sqlite（状态真源）
```

### 3.2 工资流
```
宝旺趟数/伟豪账单 + 飞书名册 + 台账报销加项
  → payroll.compute（规则求值）
  → payroll.verify（独立复算 + 8 类核对）
  → payroll.preview（待确认，定时终点）
  → payroll.confirm（发起人 token）
  → payroll.dispatch（一人一条私发）
```

### 3.3 报单流（新增）
```
飞书群运输单（文本/图片/附件）
  → intake.parse_messages / parse_table（字段别名识别）
  → resolve_drivers（归属 + 别名归一）
  → dedupe（批内 + 历史池 seen.jsonl）
  → build_data_source（标准 xlsx，列来自配置）
  → monthly_sheet.run --source（各司机报表新月份 sheet）
```

### 3.4 汇总流
```
各司机月份 sheet（运费/工资/支出标签与明细）
  → 识别（label→detail→derive 优先级，同义去重、重叠反推）
  → 净利润 = 收入 − 工资 − 支出
  → 只与上月环比（可比性阈值）
  → {年}{月}汇总.xlsx（月度汇总/项目明细/口径与校验）
```

## 四、共享与依赖

- **配置真源**：各内置模块自己的配置；本 skill 的 `modules.json` 只声明内置模块根与 action 命令。
- **报销数据是跨模块枢纽**：报销台账同时被工资（加项）、月度制表（并入报销明细）消费；
  本 skill 统一使用 `modules/reimbursement/state/ledger.sqlite`，不再读外部 skill 台账。
- **司机名册**：报销用 `driver_roster`（报表文件名 + 群成员），工资用飞书通讯录/群为主源，
  报单用 `intake.driver_from` + `drivers.aliases`；三套口径各自保留，不强行统一（避免回归）。
- **飞书通道**：读取固定 `--as user`，发送固定 bot；bot 自检在各 skill 发送前执行。
