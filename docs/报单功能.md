# 报单功能（本 skill 新增）

## 目标

把飞书群里司机/调度发的运输单，自动整理成每位司机的月度报表，格式沿用现有司机报表。

## 输入形态（`intake.accepted_sources`）

| 形态 | 消息类型 | 处理方式 |
|---|---|---|
| 文本运输单 | text | 解析 `字段: 值` 或按 `data_source.columns` 顺序对齐的值序列 |
| 图片运输单 | image / post | 标记 `_needs_transcription`，**不猜数**；用视觉能力转录成表格后以 `--attachment` 传入 |
| 附件表格 | file/xlsx/csv | 按表头别名映射字段（`parse_table`） |

群消息来自 `lark-cli im +chat-messages-list --as user --page-all --order asc
--no-reactions --download-resources --format json`，窗口 `intake.window_days` 天。
（`--as bot` 会报 230002，故固定 user；发送另用 bot。）

## 字段识别

语义键与别名在 `config/config.example.json` 的 `intake.fields`：

```
date       日期 / 出车日期 / date
driver     司机 / 司机姓名 / 姓名 / 名字 / driver
business   业务 / 委托方 / 公司
plate      车牌 / 车牌号 / 车辆
trip       趟次 / 车次 / 次数
route      路线 / 运输地点 / 线路
km         公里数 / 公里 / 里程 / km
wage       工资 / 工资（元） / 运费
settle     路线结算 / 结算
reimburse  报销 / 报销金额
```

`match_alias` 采用**最长别名优先**，避免「司机」抢匹配「司机姓名」等。
识别不出的字段留空；`required_fields` 缺失的行在 `plan` 里列出，不臆造。

## 司机归属

`intake.driver_from` 三选一：
- `field_only`：只认运输单里的司机字段；
- `sender_only`：只认消息发送者；
- `sender_or_field`（默认）：字段优先，其次发送者。

归一后再过 `drivers.aliases`（如异体字 `幸荣超 → 辛荣超`）。无法归属的记录进入 `unknown`
列表，**不写报表**。

## 去重

`dedup.key_fields`（默认 `message_id + driver + date + route + km + trip`）组成 SHA256 键：
- 批内：本轮相同键只留首条；
- 历史池：`state/intake/seen.jsonl`，通过的记录即时落盘，下次重发即命中跳过。

与报销去重**相互独立**：报销四方池管凭证，报单历史池管运输单，互不干扰、不重复实现。

## 生成数据源

`data_source.columns` 定义输出列，默认：
`日期 / 业务 / 车牌 / 司机 / 趟次 / 路线 / 公里数 / 工资 / 路线结算`。
每列通过别名反查语义键取值，写出 `state/intake/{year}年{month}月运输单.xlsx`。

## 写入报表

```
logistics intake run --messages msgs.json \
  --attachment trips.xlsx --year 2026 --month 8 [--no-dry-run]
```

- 调用内置 `monthly_sheet.run --source <数据源> --year --month`，
  把数据按司机填入各自 `{司机}{年}.xlsx` 的 `{year}年{month}月` sheet；
- 写入是 zip 层精确插入：备份 + 回读校验 + 失败回滚，保护 WPS 特有部件；
- **默认 dry-run**，只有 `--no-dry-run` 才落盘；
- 目标司机报表不存在时按 `write.on_missing_target`/月度制表 `on_missing_target` 报告并跳过，
  不新建文件。

## 命令速查

```bash
python3 scripts/logistics.py intake parse --messages msgs.json --out parsed.json
python3 scripts/logistics.py intake plan  --messages msgs.json --year 2026 --month 8
python3 scripts/logistics.py intake run   --messages msgs.json --attachment trips.xlsx \
       --year 2026 --month 8 --no-dry-run
python3 scripts/logistics.py intake selftest
```

## 自测

`selftest` 在临时目录用虚构司机「甲乙丙」验证：字段识别、图片标待转录不猜数、
司机归属、批内+历史去重、分组、数据源生成。不写真表、不连飞书。
