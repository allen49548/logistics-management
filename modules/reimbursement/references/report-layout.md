## 二、月份 sheet 命名（不统一，必须按序匹配）

| 命名风格 | 示例 | 出现在 |
|---|---|---|
| `YYYY.M` | `2026.8`、`2026.11` | 多数司机（劳辉厚、康国强、杨海湘、王博成、蒙祖友、贾燕斌、辛荣超） |
| `M月` | `1月`、`2月` | 周小毛 |
| `M月<后缀>` | `9月宝旺` | 周小毛 |
| 非月份 | `路线费用,车牌` | 参数表，**排除** |

匹配顺序：

1. 精确 `YYYY.M`（M 不补零，如 `2026.9`）；
2. 精确 `M月`；
3. 以 `M月` 开头的唯一 sheet（如 `9月宝旺`）；
4. 以上命中 **0 个 → 异常「找不到月份 sheet」，不新建 sheet**；命中 **≥2 个 → 异常「月份 sheet 歧义」，不猜**。

## 三、报销项定位（历史方式 · 仅供审计，当前流程不再使用）

> 自 2026-11-14 23:53 起，写入统一走「报销明细」sheet（见文首 ★ 段落）。
> 本节保留用于理解旧报表结构与审计历史运行清单，**其异常判定不再阻断入账**。

报表底部是「工资支出 / 报销支出 / 车贷支出 / 净利润」等汇总块，**没有固定列**，各司机、各月份都可能不同（实测标签落在 E/F/G/H 列，金额通常紧邻右侧）。

定位算法（只读）：

1. 在目标 sheet 中扫描所有文本单元格，筛出含 `报销` 且不含 `备注/说明` 的标签，形如 `报销`、`报销支出`、`总报销`、`报销合计`。
2. 从标签列向右最多 3 格，取第一个**数值型**单元格作为报销金额单元格；中间遇到文本备注（如 `500管理费`、`包含500管理费`）继续右移。
3. 候选金额是公式（`=` 开头）→ 异常，不覆盖公式。
4. 候选金额非数值或为空 → 异常「报销项无有效数值」，不自动填 0、不新增行。
5. **命中 0 个 → 异常「找不到报销项」；命中 ≥2 个 → 异常「报销项歧义」**，两者都不写入，把候选坐标与现值列进清单供人工裁决。

**已知会触发异常的情况（实测）**：

- `王博成2026.xlsx / 2026.11` 有两处报销标签：`H37 报销支出 = 1133`、`H41 报销 = 650` → 歧义，须人工指定累加到哪一个。
- `劳辉厚2026.xlsx` 的 `2026.1/2/3/4/5`、`康国强2026.xlsx / 2026.6`、`蒙祖友2026.xlsx / 2026.1–5`：有「报销」标签但右侧无数值。
- `周小毛2026.xlsx` 仅 `9月宝旺` sheet 有「报销 1000」，其余月份 sheet 无报销项。
- 部分司机 10 月、11 月 sheet 的报销值已包含管理费口径，累加时只做加法，不改口径、不重算合计。

## 四、写入

- 写入值：`新值 = 原值 + 本次金额`，写成数值（int/float），**不是公式、不是文本**；保留原单元格格式。
- 只改这一个单元格；不动合计行、不动其他支出项、不动公式、不插行列。
- 写入前把整个 `.xlsx` 原样复制到 `state/backups/<运行日期>/`，确认备份成功再写；备份失败即中止该文件写入。
- 写入后回读校验：新值与预期差异 > 0.01 → 记异常并按备份回滚。
- 通道优先级：本地 editor SDK（可保留公式/格式）> openpyxl（`data_only=False` 打开再 `save()`）> 云端 sheet 工具（仅 `cloud_sync.enabled=true` 时）。绝不整表覆盖、绝不使用 upload_replace_file 全量覆盖。
