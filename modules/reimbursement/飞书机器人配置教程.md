# 飞书机器人配置教程（所有工具通用）

当任一工具提示"飞书机器人未配置 / 未授权 / 不在群"时，按本教程排查配置。配置完成后通知会自动恢复，无需改代码。

统一的通知机器人：**廖浩成's Feishu CLI**（app id：`cli_aa7fca0a72ba9bb4`）。所有对外通知都由它发出。本教程不依赖 WorkBuddy。

---

## 快速自检（先跑这条）

```bash
python3 modules/reimbursement/scripts/bot_check.py
# 若 lark-cli 不在 PATH：
export LOGISTICS_LARK_CLI=/absolute/path/to/lark-cli
```

- 输出 `"bot_setup_required": false` → 配置正常，无需处理。
- 输出 `"bot_setup_required": true` → 看 `issues` 和 `reminder` 字段，按下面对应步骤修。

（每个业务模块目录下也有自己的 `scripts/bot_check.py`，可带 `--chat-id` 检查机器人是否在目标群。）

---

## 第 1 步：确认 lark-cli 可用

`lark-cli` 是发送飞书消息的工具。只需满足以下任一条件：

1. `lark-cli` 在 PATH 中；
2. 设置 `LOGISTICS_LARK_CLI` 或 `LARK_CLI` 指向可执行文件；
3. WorkBuddy 用户启用「飞书」连接器，其安装路径会自动作为兜底。

验证：

```bash
lark-cli --help
# 或
LOGISTICS_LARK_CLI=/absolute/path/to/lark-cli python3 modules/reimbursement/scripts/bot_check.py
```

- 提示 `command not found` → 安装/指定 `lark-cli`；WorkBuddy 用户可在客户端左下角「+」→ 连接器 → 启用「飞书」。

## 第 2 步：给机器人授权登录（最常见原因）

机器人身份（bot）需要登录授权，token 会过期，过期就必须重新登录。

```bash
export PATH="$HOME/.workbuddy/binaries/node/cli-connector-packages/bin:$PATH"
lark-cli auth login
```

按提示在浏览器 / 飞书里用管理员账号扫码或确认授权。完成后验证：

```bash
lark-cli auth status
```

看到 `bot → Bot identity: ready` 即成功。若 skill 报"机器人未授权 / unauthorized / no permission"，基本就是这一步——重新 `auth login` 即可。

## 第 3 步：把机器人拉进目标群

机器人只能给自己所在的群发消息。若群消息失败、降级到私聊，多半是机器人不在群里。

在飞书里打开目标群 → 群设置 → 添加机器人 → 搜索并添加「**廖浩成's Feishu CLI**」。

验证：

```bash
lark-cli im +chat-list --as bot --page-all
```

输出里能看到目标群（如「物流部」「小黑瓶丹竹头店」「小黑瓶福田店」）即成功。

## 第 4 步：核对 skill 的群 chat_id 配置

群 `chat_id` 是 `oc_` 开头的一串字符，配置在各 skill 的 `config.json`（报销）或 config 目录里。

- 报销：`reimbursement/config.json` 的 `chat_whitelist`，目标群需 `notify: true`。
- 美甲店：`nail-salon/scripts/run_round.py` 的 `SHOPS` 映射。
- 司机工资：`driver-wage/config/local/payroll.json` 的 `notify`。
- 美团榜：`meituan-rank/config.json` 的 `chat_whitelist` / `report_to_chat_id`。

查群 id：

```bash
lark-cli im +chat-list --as user
```

若换了新的群，把新群的 `oc_xxx` 按对应格式填进去，并确认 `notify: true`（报销的新群默认 `notify: false`，需人工确认后改 true——这是防串群保护）。

## 第 5 步：验证

重新触发一次对应 skill（或让我重跑），不再出现"机器人未配置"提醒即配置成功。

---

## 常见报错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `command not found: lark-cli` | CLI 未装 / 不在 PATH | 第 1 步，放进 PATH 或设置 `LOGISTICS_LARK_CLI` |
| bot 身份不是 ready / unauthorized / no permission | 机器人授权过期或未授权 | 第 2 步，`lark-cli auth login` |
| bot 不在目标群 / 群消息降级私聊 | 机器人没被拉进群 | 第 3 步，飞书群里添加机器人 |
| 群 id 不在白名单 | 配置缺群或 notify=false | 第 4 步，补 `chat_id` 并设 `notify: true` |
| user 身份发送失败 | 个人账号 scope 不足 | 统一走 bot；确需 user 时 `lark-cli auth login --scope im:message.send_as_user` |
