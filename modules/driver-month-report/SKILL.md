# 司机月度报表生成器

## 用途

把「每位司机一个 xlsx、表内按月分 sheet」的原始台账，汇总成一份管理者可直接读的月度报表：
识别 **运费收入 / 工资 / 其他支出** → 按统一口径算 **每月净利润** → 与 **上一个月** 做 **环比** → 突出展示。

所有规则放在 `config/`：

- `config/report.json`：月份参数、源目录、输出与清理策略、金额解析、取数优先级、净利润与环比公式、列与 KPI、文案与配色；
- `config/item_rules.json`：项目 key、类别与角色、识别别名（顺序即优先级）、明细表头关键词、重叠科目关系。

## 何时用

- 用户要「重新生成 8 月报表 / 月度汇总 / 环比报表」；
- 用户要按司机看「工资、报销、车贷、利润」并做上月对比；
- 用户改了项目叫法或口径，要按新配置重出一版（不重复、不叠加旧结果）。

## 怎么跑

```bash
cd modules/driver-month-report
python3 scripts/cli.py generate                 # 默认 2026-08，环比 2026-07
python3 scripts/cli.py generate --month 2026-09 --previous 2026-08
python3 scripts/cli.py inspect                  # 只看识别到的原始数值
python3 scripts/cli.py generate --dry-run       # 演算不落盘
```

输出：`<source.driver_dir>/2026年8月汇总.xlsx`，三个工作表（月度汇总 / 项目明细 / 口径与校验）。

## 硬性口径（不可静默违反）

1. **先清理再生成**：同月旧报表必须按 `output.overwrite` 处理（默认搬到 `.recycle/<时间戳>/`），
   绝不允许两份同名同月报表并存或数据行重复。
2. **不硬编码**：项目名、别名、金额、月份、公式一律读配置；改口径只改 JSON。
3. **同义字段去重**：同一项目多个别名只取一个值（车贷支出 / 还车贷 / 车贷月供 …），
   同值重复标签只保留一条，**禁止跨别名累加**。
4. **重叠科目不重复计入**：如「奖金」是否已含在「工资支出」里，用源表净利润反推验证后决定，
   并在明细与说明里写明依据。
5. **只与上一个月环比**：`previous_period` 必须是 `current_period` 的上一个月，配置不自洽时直接报错退出。
6. **不臆造**：缺工作表、缺标签、缺支出科目、源表净利润与计算值不一致，都要写进「异常/缺失说明」，
   宁可标「无法计算 / 不可比」，也不编数。
7. **涨红跌绿**：环比上升用红、下降用绿；不可比行的环比单元格置灰。
